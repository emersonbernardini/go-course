Operadores aritméticos

Operadores aritméticos realizam cálculos matemáticos. Em Go, eles só funcionam entre operandos do mesmo tipo — sem conversão implícita, como vimos no módulo anterior.

go operadores aritméticos 
a, b := 10, 3

fmt.Println(a + b)   // 13  — soma
fmt.Println(a - b)   // 7   — subtração
fmt.Println(a * b)   // 30  — multiplicação
fmt.Println(a / b)   // 3   — divisão inteira (trunca)
fmt.Println(a % b)   // 1   — módulo (resto da divisão)

// Divisão inteira vs ponto flutuante
fmt.Println(10 / 3)          // 3   — divisão inteira, trunca
fmt.Println(10.0 / 3.0)      // 3.3333333333333335 — float64
fmt.Println(float64(10) / 3) // 3.3333333333333335

Operadores de incremento e decremento

Go tem ++ e --, mas com uma diferença importante em relação a C e Java: são instruções, não expressões. Você não pode usá-los em atribuições ou como parte de expressões maiores.

go 
x := 10
x++  // x = 11 — instrução, não expressão
x--  // x = 10

// ERROS — não existem em Go:
// y := x++   // não é expressão, não retorna valor
// if x++ > 5 // não pode estar dentro de expressão
// ++x        // não existe pré-incremento

Operadores relacionais

Operadores relacionais comparam dois valores e sempre retornam um bool. São usados para tomar decisões em condicionais e laços — que estudaremos nos próximos módulos.

go operadores relacionais 
a, b := 10, 20

fmt.Println(a == b)  // false — igual a
fmt.Println(a != b)  // true  — diferente de
fmt.Println(a < b)   // true  — menor que
fmt.Println(a > b)   // false — maior que
fmt.Println(a <= b)  // true  — menor ou igual
fmt.Println(a >= b)  // false — maior ou igual

Comparação de strings

Strings podem ser comparadas com == e !=, além de <, >, etc., que comparam lexicograficamente (como em um dicionário, byte a byte):

go 
fmt.Println("abc" == "abc")  // true
fmt.Println("abc" < "abd")   // true — 'c' < 'd' lexicograficamente
fmt.Println("B" < "a")       // true — maiúsculas têm código menor que minúsculas em ASCII
Comparação requer mesmo tipo
Assim como operadores aritméticos, relacionais exigem que os dois operandos sejam do mesmo tipo. 1 == 1.0 parece óbvio, mas em Go é um erro de compilação: int e float64 são tipos distintos.

Operadores lógicos

Operadores lógicos combinam expressões booleanas. Go tem três: && (AND), || (OR) e ! (NOT).

go operadores lógicos 
a := true
b := false

fmt.Println(a && b)  // false — AND: verdadeiro se ambos forem true
fmt.Println(a || b)  // true  — OR: verdadeiro se pelo menos um for true
fmt.Println(!a)      // false — NOT: inverte o valor

Avaliação em curto-circuito

Go usa avaliação em curto-circuito (short-circuit evaluation): em uma expressão &&, se o lado esquerdo for false, o lado direito não é avaliado. Em ||, se o lado esquerdo for true, o direito não é avaliado.

Isso não é apenas uma otimização — é um comportamento que você pode (e deve) usar intencionalmente:

go 
// Padrão comum: verifica se slice não é nil antes de acessar
var s []int
if s != nil && len(s) > 0 {
    fmt.Println(s[0])
}
// Se s == nil, len(s) não é avaliado — sem panic

// Padrão comum: usa valor default se condição falhar
nome := ""
if nome == "" || nome == "anônimo" {
    nome = "visitante"
}

Operadores bitwise

Operadores bitwise operam diretamente nos bits de um valor inteiro. São essenciais para programação de sistemas, protocolos de rede, manipulação de flags e otimizações específicas.

go operadores bitwise 
a := 0b1010  // 10 em decimal
b := 0b1100  // 12 em decimal

fmt.Printf("%04b\n", a&b)   // 1000 (8)  — AND bit a bit
fmt.Printf("%04b\n", a|b)   // 1110 (14) — OR bit a bit
fmt.Printf("%04b\n", a^b)   // 0110 (6)  — XOR bit a bit
fmt.Printf("%04b\n", a&^b)  // 0010 (2)  — AND NOT (bit clear) — exclusivo de Go

fmt.Println(a << 1)  // 20 — shift left: multiplica por 2
fmt.Println(a >> 1)  // 5  — shift right: divide por 2

Caso de uso real: flags de permissão

Vimos no módulo anterior como iota com shift cria flags. Aqui está o padrão completo de uso com operadores bitwise:

go 
type Perm uint8

const (
    Leitura  Perm = 1 << iota  // 0001
    Escrita                     // 0010
    Execucao                    // 0100
)

// Combinar permissões com OR
permissao := Leitura | Escrita  // 0011

// Verificar se tem uma permissão com AND
if permissao&Leitura != 0 {
    fmt.Println("pode ler")
}

// Remover uma permissão com AND NOT
permissao = permissao &^ Escrita  // remove escrita: 0001

// Adicionar uma permissão com OR
permissao = permissao | Execucao  // adiciona execução: 0101
Literais binários, octal e hexadecimal
Go aceita literais inteiros em diferentes bases: 0b1010 (binário), 0o17 (octal), 0xFF (hexadecimal). Prefixos 0b, 0o e 0x. Úteis ao trabalhar com operações bitwise, endereços de memória ou protocolos.

Operadores de atribuição

Operadores de atribuição combinam uma operação com a atribuição do resultado à variável. São atalhos que tornam o código mais conciso sem perder clareza.

go operadores de atribuição 
x := 10

x += 5   // x = x + 5  → 15
x -= 3   // x = x - 3  → 12
x *= 2   // x = x * 2  → 24
x /= 4   // x = x / 4  → 6
x %= 4   // x = x % 4  → 2

// Atribuição bitwise
x &= 0b1111   // x = x & 0b1111
x |= 0b0001   // x = x | 0b0001
x ^= 0b0011   // x = x ^ 0b0011
x <<= 1       // x = x << 1
x >>= 1       // x = x >> 1

// Atribuição múltipla — troca de valores sem temporária
a, b := 1, 2
a, b = b, a
fmt.Println(a, b)  // 2 1
Atribuição não é expressão em Go
Em C é possível escrever if (x = getValor()) { } — atribuição dentro de condição. Em Go, atribuição é uma instrução, não uma expressão. Isso elimina o bug clássico de escrever = quando queria ==.

Precedência de operadores

Quando uma expressão tem múltiplos operadores, a precedência determina a ordem de avaliação. Operadores com maior precedência são avaliados primeiro. Go tem 5 níveis de precedência para operadores binários:

Precedência Operadores
5 (maior) * / % << >> & &^
4 + - | ^
3 == != < <= > >=
2 &&
1 (menor) ||
go precedência na prática 
// * tem maior precedência que +
resultado := 2 + 3*4   // 2 + 12 = 14  (não 20)

// Parênteses forçam a ordem
resultado2 := (2 + 3) * 4  // 5 * 4 = 20

// && tem maior precedência que ||
// a || b && c  é interpretado como  a || (b && c)
x := true || false && false  // true || (false && false) = true || false = true

// Condição composta comum
idade := 25
temCNH := true
if idade >= 18 && temCNH {
    fmt.Println("pode dirigir")
}
Dica: use parênteses para clareza
Mesmo conhecendo a tabela de precedência, use parênteses quando a expressão envolver mais de dois operadores diferentes. (a + b) * c é mais legível que confiar na memória do leitor sobre precedência. Código claro supera código inteligente.
Quiz · Questão 1 de 3 Verificação de entendimento

Qual é o resultado de fmt.Println(7 / 2, 7 % 2)?

✓ Correto! 7 / 2 em inteiros é 3 (trunca, não arredonda). 7 % 2 é 1 (resto de 7 ÷ 2). Para obter 3.5, converta antes: float64(7) / 2.
Quiz · Questão 2 de 3 Verificação de entendimento

Dado o código abaixo, a função custosa() é chamada?

go 
condicao := false
if condicao && custosa() {
    fmt.Println("executou")
}
✓ Correto! Com &&, se o operando esquerdo for false, o resultado já é false independente do direito. Go garante que o lado direito não é avaliado. Isso é o curto-circuito — comportamento definido pela especificação da linguagem, não pelo compilador.
Quiz · Questão 3 de 3 Verificação de entendimento

Qual é o valor de x após a expressão abaixo?

go 
x := true || false && false
✓ Correto! && tem precedência 2 e || tem precedência 1, então && é avaliado primeiro: false && false = false, e então true || false = true. Resultado: true.
Exercício 1 — Incremento Aplicação prática

Por que o código abaixo não compila?

go 
x := 5
y := x++
fmt.Println(y)
✓ Correto! Em C/Java, y = x++ é válido porque x++ é uma expressão que retorna o valor anterior de x. Em Go, x++ é uma instrução sem valor de retorno. A solução é separá-los: y := x seguido de x++.
Exercício 2 — Operação bitwise Aplicação prática

Um sistema de permissões tem as flags Leitura = 1, Escrita = 2 e Execucao = 4. Um usuário tem permissao = 7 (todas as permissões). Qual operação remove apenas a permissão de escrita?

✓ Correto! O operador &^ (AND NOT / bit clear) é o jeito idiomático de limpar bits em Go. 7 &^ 2 = 0b111 &^ 0b010 = 0b101 = 5 (leitura + execução). ^ Escrita sozinho funcionaria apenas em sistemas onde você tem certeza que o bit estava setado — &^ é seguro independentemente do estado atual do bit.
