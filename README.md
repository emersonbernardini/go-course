# GoCourse

Plataforma de estudo de Go, do zero ao avançado. Gratuita, em português e pensada para funcionar offline.

**Acesse:** https://go-course.netlify.app

## Conteúdo

34 módulos organizados em 11 blocos, onde cada bloco depende do anterior e não há saltos de dificuldade. No total são 182 tópicos, 102 quizzes e 68 exercícios.

| Bloco | Tema |
| ----- | ---- |
| 0 | Fundação |
| 1 | Fundamentos da linguagem |
| 2 | Controle de fluxo |
| 3 | Estruturas de dados |
| 4 | Funções |
| 5 | Tipos compostos e abstração |
| 6 | Tratamento de erros |
| 7 | Pacotes e módulos |
| 8 | Concorrência |
| 9 | Stdlib essencial |
| 10 | Tópicos avançados |

A plataforma acompanha o progresso do estudante: módulos concluídos, exercícios feitos e sequência de dias de estudo.

## Stack

HTML, CSS e JavaScript, sem etapa de build. Hospedado no Netlify.

## Executar localmente

Por ser um site estático, qualquer servidor de arquivos serve:

```bash
git clone https://github.com/emersonbernardini/go-course.git
cd go-course
bunx serve .
```
